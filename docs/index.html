Subdomains für
Völser Initiativen & Vereine

Die Domain voels.org steht für gemeinschaftliche nicht-kommerzielle Projekte, Initiativen und Vereine in der Marktgemeinde Völs zur Verfügung.

Wenn du eine kostenlose Subdomain (z. B. deinprojekt.voels.org) für deine Initiative oder deinen Verein benötigst, melde dich gerne bei mir:

📩 Jens Klein – jk@kleinundpartner.at

Richtlinien

  • ✅ Nur für Organisationen, Initiativen und Vereine mit Bezug zu Völs.
  • ✅ Die Nutzung muss im Einklang mit geltenden Gesetzen stehen.
  • ✅ Keine diskriminierenden, illegalen oder unangemessenen Inhalte.

Ich freue mich auf eure Anfragen!

Git Repository

Auf der Plattform Github gibt es eine Organisation github.com/voelsorg in dem jede/r, der/die die obigen Kriterien erfüllt, die Möglichkeit hat, ein Repository zu erstellen oder an einem Projekt teilzunehmen.
